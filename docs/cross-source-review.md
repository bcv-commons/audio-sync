## How to confirm a pairing

If the audio and text are the same translation (just from different publishers),
add a `same_text` entry to `data/version-crossref.json`:

```json
{
  "ISO": {
    "DBS_ID": { "dbt": "AUDIO_FILESET", "same_text": "TEXT_DBS_ID" }
  }
}
```

After confirmation, run `make align ISO=<iso>` to merge and align.
